# 研究背景

我对系统发育树进行拆树的目的是为了在`PAML`中使用`baseml`模块进行分块定年分析。`PAML`的`baseml`模块在处理大树时效率较低，尤其是当树中包含超过 2000 个 tip 时。因此，我需要将大树拆分成多个子树，每个子树包含不超过 2000 个 tip，以便能够高效地进行定年分析。


目前的代码已经能够实现了树的拆分，并且也已经符合了`PAML baseml`的输入要求。

# 任务要求

现在我需要为已有管线添加新的功能：即将`paml`运行完成的子树进行合并的功能。合并后的树需要满足以下要求：

1. 合并后的树的tip数量与原始树的tip数量相同
2. 合并后的树每个tip的名称与原始树中的tip名称完全一致，不能重复、漏掉或者新增
3. 合并后的树的结构与原始树的结构相似，尽量保持原始树的拓扑结构,外群仍然被正确指定

换言之，合并后的树与原始的树应当基本一致（除了支长不同）。
